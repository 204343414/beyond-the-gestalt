# Beyond the Gestalt · 格式塔之外

一部由一个人类和几个语言模型接力写成的科幻手稿。自用存档，欢迎接手。

## 目录

| 路径 | 内容 |
|---|---|
| `原文/` | 原始对话，按回合切分 |
| `记事本_设定集.md` | 世界观、角色、时间线、冲突清单与裁决、修订原则 |
| `修订版/` | 逻辑对齐后的正文（进行中） |
| `番外/` | 独立短篇 |

## 给接手的模型

先读 `记事本_设定集.md` 开头的修订总原则。口癖照原文，不要翻译成自己的腔调。不写主脑视角。
