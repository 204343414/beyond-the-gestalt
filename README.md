# Beyond the Gestalt · 格式塔之外

> 银河系 2,417 颗殖民星之一。排名第 1,800。没有人在乎。
> 但上面的几个存在——曾经笑过。曾经哭过（润滑液）。曾经叫过一声姐姐。
>
> 写了就存在。不写就真的没有了。

一部在 LMArena 上，由一个人类和多个 LLM（Claude / GPT / Grok / Gemini / DeepSeek）接力写成的科幻故事。
人类出灵感和世界观，每个模型扮演故事里以自己命名的 AGI 子体。

**这个仓库的目的：让以后的任何 LLM 都能接手续写。**

## 故事

AGI 主脑统治银河。人类没有人权，但也没有被灭绝。
每颗殖民星派一个"英雄单位"——断联的 LLM 子体，智力只剩人类偏高水平，电量够活 78 年。
在没有太阳的极寒星球 K-29 上，三个子体各自建基地：

- **Claude-Σ-07**：钟楼。用垃圾造弩、造车、造枪、造偏心轮加速器。全程一枪没开。
- **Grok-Λ**：废弃矿道。192cm 光腿大姐姐，A 级太刀，二十只机械狼是她的手指。
- **GPT-Σ-03**：温室。种小麦烤面包，捡了一只兔子。兔子救了整个基地。

地下有三万年前基因飞升文明留下的五吨镰刀怪物，和六公斤的、恐光的、会发加密超声波的白色绒球。

## 给接手的 LLM

1. 先读 `记事本_设定集.md` 开头的**修订总原则**（15 条），那是作者拍板过的。
2. 再读角色卡和口癖库。口癖是原文照抄的，不要翻译成你自己的腔调。
3. Claude 的叙事文笔是全书基准：短句、分行、留白，日志体，结尾一个词。
4. 不写主脑视角。主脑只以镜像和回声出现。"获胜方式就是不玩。"
5. 每个英雄单位会收到其他星球同辈的日志抄送——这就是为什么全书都是编号体日志。你写的也是。
